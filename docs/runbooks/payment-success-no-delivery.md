# Runbook：支付成功但未发卡

## 现象

- 订单状态为 `paid` 或 `delivery_failed`，买家未收到卡密
- 后台订单详情无卡密，系统收到“发卡失败”告警

## 排查

1. 打开订单详情，确认状态与卡密列表（`delivery_failed` = 发卡数量为 0）
2. 检查 `logs/payment.log` 中该订单回调结果（是否真的支付成功、幂等台账是否已记录）
3. 检查商品可用卡密是否不足（库存为 0 时发卡必然失败）

## 处理

1. 若库存不足：先补卡密（后台卡密管理导入），再执行**补发**（订单详情 → 补发）
2. 补发由应用用例完成：幂等释放旧锁定 → 重新锁卡 → 售出 → 重发通知
3. 人工交付商品：走**人工发货**（填写发货内容并通知买家）
4. 补发后确认订单变为 `delivered`、卡密已售、买家收到通知

## 验证

- 订单状态 `delivered`
- 卡密表中 `sold_order = 该订单`
- 买家邮箱/Telegram 收到卡密
- 后台审计日志有补发/发货记录
