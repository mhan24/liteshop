# ADR-0004：为什么接口定义放在使用方

## 决策

端口接口（OrderRepository、InventoryRepository、PaymentGateway、NotifierPort 等）定义在**使用它们的模块的 application/ports.go**，而不是集中到全局 `interfaces` 包；第三方实现（SQLite 仓储、支付网关、通知适配器）反向实现这些接口。

## 原因

- 接口描述的是“业务需要什么能力”，不是“第三方提供什么能力”
- 消费者定义契约，实现方可按需替换，新增支付/通知渠道不改业务核心
- 避免全局接口包膨胀与反向依赖（业务层依赖具体 SDK）

## 权衡

- 同一能力若被多模块使用需各自声明或通过组合根适配；当前通过端口注入已满足

## 状态

已接受。
