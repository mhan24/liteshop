## 四、重点复核结论（全部通过）

- **会话**：DB 持久化 + HMAC Cookie + `__Host-`/普通名切换 + 滑动续期 + 登出/删号/恢复/重置即时吊销；写库失败返回 500（不产生无效 Cookie）。✅
- **订单访问**：邮箱查询模糊响应（不返回订单号/URL）；查看链接只发往登记邮箱；`/orders/links` 单封邮件 + 按邮箱冷却；新订单令牌恒定时间比对；旧订单兼容已文档化。✅
- **支付链路**：回调 MD5 验签、`MarkPaidAndDeliver` 单事务幂等、重复回调不重复发卡、通知异步且买家邮件收敛为一封。✅
- **状态机**：手动改状态校验枚举与合法迁移；cancelled/expired 走原子流程；补发仅限已支付类状态；过期接口对非法状态返回 400。✅
- **认证**：PBKDF2-SHA256 10 万次 + 恒定时间；登录时序均摊防枚举；TOTP AES-GCM + 一次性令牌；登录/验证/下单/查询/解锁/发链接均有限流。✅
- **注入/XSS**：SQL 全参数化；markdown `html:false`；Vue/Nuxt 转义；后台 CSP 含 `unsafe-eval`（vue-i18n 所需）；CSV 公式注入防护；图片 URL 限 http/https；site_links 限 50。✅
- **供应链**：Go 1.26.5 + modernc v1.56.0（全测试绿）；storefront/admin-ui `npm audit` 均 0 漏洞；无外部 CDN 运行时依赖；Swagger 本地页。✅
- **运维**：数据目录 700 / DB 600 / 备份 root-only、systemd UMask=0077、HSTS、`NUXT_PUBLIC_SITE_URL` 与 `SHOP_SETUP_TOKEN` 已配置、三服务 active、`/health`/后台/公网 200、`/docs` 匿名 303、`/orders/links` 模糊返回 ok。✅
