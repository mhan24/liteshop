# 端到端测试

目录：

```
tests/e2e/
├── storefront/   前台核心购买流程
└── admin/        后台管理流程
```

建议基于 Playwright（storefront 用 Nuxt 的 `start` 服务，admin 用 Go 后端 + 前台 SSR）。

## 前台核心流程（至少覆盖）

1. 浏览商品：首页列表/搜索/分类筛选
2. 创建订单：选择商品数量、填写邮箱、选支付方式
3. 模拟支付回调：直接向 `/notify/bepusdt` 投递合法回调
4. 查看卡密：支付后凭查看链接展示卡密
5. 取消未支付订单：订单页取消并释放库存
6. 邮箱查询订单：仅凭邮箱找回订单并发送查看链接
7. 后台补发：对已支付未发卡订单执行补发/重发通知
